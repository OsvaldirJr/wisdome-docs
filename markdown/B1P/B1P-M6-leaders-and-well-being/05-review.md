# Review — Leaders and Well-being
**B1P-M6** — Revisão final do curso! Revise reported speech, past perfect, second conditional e linguagem de decisão — e faça o projeto final.

## O que você aprendeu neste módulo
- Relatar o que outras pessoas disseram e perguntaram (reported speech)
- Contar biografias e histórias com tempos narrativos e past perfect
- Falar sobre hipóteses e hábitos saudáveis com o second conditional
- Comparar opções e justificar decisões
- Fazer uma apresentação final de 5 minutos no estilo TED

## ✏️ Review exercises

### Exercise 1 — Module review

_Choose the correct option._

1. She ___ me that she was leaving.  
   ( ) said · ( ) told · ( ) asked
2. He asked me where ___.  
   ( ) did I live · ( ) I lived · ( ) do I live
3. By the time we arrived, the show ___.  
   ( ) started · ( ) had started · ( ) has started
4. If I ___ more time, I'd learn to cook.  
   ( ) have · ( ) had · ( ) would have
5. It's worth ___ a second opinion.  
   ( ) to get · ( ) getting · ( ) get

### Exercise 2 — B1+ general review

_Questions from the whole B1+ level._

1. More and more people ___ from home.  
   ( ) work · ( ) are working
2. I'm not used to ___ up so early.  
   ( ) wake · ( ) waking · ( ) woke
3. I have ___ money, so let's go out!  
   ( ) little · ( ) a little · ( ) few
4. That's the designer ___ logo won the award.  
   ( ) who · ( ) whose · ( ) which
5. She ___ forgotten. She never misses meetings.  
   ( ) must have · ( ) should have · ( ) can
6. A new park ___ right now.  
   ( ) is building · ( ) is being built · ( ) has built

## 🎤 Free conversation

Conversa final do curso: grave um vídeo de 5 minutos respondendo às perguntas sem ler. Depois, assista aos seus vídeos do A1, A2 e B1 e escreva 3 frases sobre sua evolução.

1. Tell me about a leader or person who inspired you and what they told you.
2. Tell me the story of a big achievement in your life — what had you done before it?
3. If you could change one thing about your lifestyle, what would it be and why?
4. Describe a difficult decision you made: what were the options and how did you decide?
5. What's the most important thing you've learned in this course?

## 🚀 Mini-projeto

**Projeto final do curso — "My TED Talk":** apresente (ao vivo ou gravado) sua palestra de 5 minutos no estilo TED, usando o roteiro que você escreveu. Critérios: estrutura (gancho → ação), clareza (sem jargão, com exemplos), variedade de estruturas do B1+, pronúncia e conexão com o público. Compartilhe com a turma e dê feedback aos colegas usando reported speech: "I liked when she said that...". Parabéns por chegar até aqui! 🎓🚀
