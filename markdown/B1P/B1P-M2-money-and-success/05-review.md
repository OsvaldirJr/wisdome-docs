# Review — Money and Success
**B1P-M2** — Revise quantificadores, present perfect x past simple, simple x continuous e linguagem de desculpas.

## O que você aprendeu neste módulo
- Falar de dinheiro e hábitos de consumo com quantificadores precisos
- Contar experiências e conquistas combinando present perfect e past simple
- Destacar processos e esforços com o present perfect continuous
- Pedir desculpas, justificar e assumir responsabilidade de forma profissional
- Discutir o que é sucesso para diferentes pessoas

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. I have ___ money saved, so I can go on the trip.  
   ( ) little · ( ) a little · ( ) few
2. Since she started the course, she ___ a lot.  
   ( ) learned · ( ) has learned
3. How long ___ for this exam?  
   ( ) have you studied · ( ) have you been studying
4. I ___ three exams this week.  
   ( ) 've taken · ( ) 've been taking
5. I should ___ the report before sending it.  
   ( ) check · ( ) have checked · ( ) checked

### Exercise 2 — Mixed practice

_Complete with the correct form._

1. I have too ___ subscriptions. (quantificador)
2. It's the first time I ___ (save) money for a whole year.
3. You ___ (not / spend) so much on that phone!

2. Estou escrevendo este livro há dois anos.

## 🎤 Free conversation

Grave um áudio de 3 minutos sobre "Minha relação com dinheiro e sucesso": seus hábitos financeiros, uma conquista que exigiu tempo (present perfect continuous), algo que você deveria ter feito diferente e o que sucesso significa para você.

1. How do you manage your money?
2. What have you been working towards lately?
3. What's your biggest achievement so far?
4. What should you have done differently in your career or studies?
5. How do you define success?
