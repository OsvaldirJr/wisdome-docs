# Review — Marketing and Communication
**B1P-M3** — Revise artigos, relative clauses, formas de futuro e linguagem de networking.

## O que você aprendeu neste módulo
- Usar artigos (a, an, the, sem artigo) com precisão em textos e apresentações
- Descrever produtos e pessoas com relative clauses (who, which, that, whose, where)
- Escolher a forma de futuro adequada (will, going to, present continuous, present simple)
- Explicar ideias complexas de forma simples para um público leigo
- Iniciar e manter conversas de networking em eventos profissionais

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. ___ people trust online reviews.  
   ( ) The · ( ) — · ( ) A
2. She's ___ engineer at ___ startup in Recife.  
   ( ) an / a · ( ) a / an · ( ) the / a
3. That's the woman ___ company won the award.  
   ( ) who · ( ) whose · ( ) which
4. My phone, ___ I bought last year, is broken.  
   ( ) that · ( ) which · ( ) what
5. Today ___ talk about three ideas. (plano)  
   ( ) I'll · ( ) I'm going to

### Exercise 2 — Mixed practice

2. The workshop ___ (start) at 3 p.m. according to the program.
3. Have you ___ Leo? He's the one who built the app.
4. It's been great ___ to you.

## 🎤 Free conversation

Grave um elevator pitch de 60 a 90 segundos sobre você ou um projeto, como se estivesse num evento internacional: quem você é, o que faz (sem jargão, com uma analogia), o que vai fazer em seguida e um convite para manter contato.

1. Describe a brand you admire and why.
2. Describe a product that didn't live up to the hype.
3. Explain something from your field as if I were 12 years old.
4. What are you going to focus on in your career next year?
5. How would you start a conversation with a stranger at a conference?

## 🚀 Mini-projeto

**Launch campaign:** em grupo, criem uma campanha de lançamento para um produto fictício: nome, público-alvo, slogan, uma descrição com relative clauses, um post para redes sociais e um pitch de 2 minutos para investidores (com previsões usando will e planos com going to).
