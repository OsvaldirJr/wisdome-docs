**C2-M5** — Revise neologismos e formação de palavras, variedades do inglês, linguagem jurídica e resumo.

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. "Brunch" is an example of a ___.  
   ( ) blend · ( ) back-formation · ( ) initialism
2. "Have you got a car?" is typically ___.  
   ( ) British · ( ) American · ( ) Indian
3. In a contract, "The tenant shall pay" means the tenant ___ pay.  
   ( ) must · ( ) will probably · ( ) may
4. You are entitled ___ a refund.  
   ( ) to · ( ) for · ( ) of
5. The second writer takes ___ with this view.  
   ( ) issue · ( ) problem · ( ) question

### Exercise 2 — Word formation

_Use the word in CAPS to form a word that fits the gap._

1. Many apps ___ learning with points and badges. (GAME)
2. The bureaucracy was absolutely ___. (KAFKA)
3. Visitors are ___ from taking photos. (PROHIBIT)

_Translate into English._

1. Os funcionários têm direito a férias remuneradas.

3. Em poucas palavras, os dois autores concordam.

## 🎤 Free conversation

Faça um "language in the world" briefing de 5 minutos: apresente três neologismos recentes explicando como foram formados, compare duas variedades do inglês com exemplos, explique um direito importante em linguagem jurídica e em plain English, e termine resumindo dois pontos de vista sobre a expansão global do inglês.

1. Which new English word would you add to the dictionary?
2. Do you prefer British or American English? Why?
3. Which right would you add to the Universal Declaration today?
4. Is summarizing a skill or an art?
5. Will English become more or less diverse in the future?
