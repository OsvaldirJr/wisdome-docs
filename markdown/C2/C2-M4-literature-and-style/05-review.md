# Review — Literature and Style
**C2-M4** — Revise voz narrativa, recursos sonoros, pontuação expressiva e linguagem de crítica.

## O que você aprendeu neste módulo
- Reconhecer e usar discurso indireto livre e presente histórico
- Usar recursos sonoros (aliteração, assonância, ritmo)
- Usar pontuação para efeito (ponto e vírgula, dois-pontos, travessão)
- Escrever uma crítica literária ou artística em nível C2

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. "She closed the door. Late again. Why did he always do this?" uses ___.  
   ( ) free indirect speech · ( ) direct speech · ( ) indirect speech
2. "The fire crackled" is an example of ___.  
   ( ) onomatopoeia · ( ) alliteration · ( ) chiasmus
3. It was late ___ everyone had gone home.  
   ( ) ; · ( ) , · ( ) :
4. It's an ambitious, ___ uneven, novel.  
   ( ) if · ( ) as · ( ) so
5. When writing about a novel, use the ___.  
   ( ) present · ( ) past perfect · ( ) future

### Exercise 2 — Fix the mistake

3. ❌ The film was very good and very interesting. → ____________________

## 🎤 Free conversation

Grave um episódio de 5 minutos de um "literary podcast": leia em voz alta um trecho curto (de domínio público ou escrito por você) com atenção ao ritmo e à pontuação, analise a voz narrativa e os recursos sonoros e termine com uma minicrítica com nuance e recomendação.

1. Which book changed the way you see the world?
2. Is it better to read literature in the original language?
3. What makes a sentence beautiful?
4. Can you recognize a writer by their style alone?
5. Which Brazilian writer should the world read next?
