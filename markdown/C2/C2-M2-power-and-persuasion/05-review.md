# Review — Power and Persuasion
**C2-M2** — Revise inversão literária, linguagem de spin, conectores formais e figuras retóricas.

## O que você aprendeu neste módulo
- Usar inversão e fronting literários (Gone are the days, Such is..., Nowhere is...)
- Identificar e desmontar eufemismos e linguagem evasiva
- Usar conectores formais raros (whereby, notwithstanding, lest, albeit, insofar as)
- Analisar e produzir figuras retóricas (quiasmo, anáfora, paralelismo)

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. ___ the days when phones had cords.  
   ( ) Gone are · ( ) Gone were · ( ) Are gone
2. "Mistakes were made" hides the ___.  
   ( ) agent · ( ) object · ( ) verb
3. The scheme was a success, ___ a costly one.  
   ( ) albeit · ( ) whereby · ( ) hence
4. "Eat to live, not live to eat" is an example of ___.  
   ( ) chiasmus · ( ) anaphora · ( ) epistrophe
5. Here ___!  
   ( ) comes he · ( ) he comes · ( ) does he come

### Exercise 2 — Transform

_Rewrite the sentences as instructed._

1. The power of the internet is so great that it can topple governments. (Such...)
2. We're letting 50 people go. (plain English)
3. Despite the delay, the project was completed. (Notwithstanding...)

_Translate into English._

1. Em nenhum lugar isso é mais evidente do que na educação.

3. Não porque é fácil, mas porque é necessário.

## 🎤 Free conversation

Faça um "rhetoric masterclass" de 5 minutos: escolha um discurso, propaganda ou comunicado real (em inglês), analise o uso de inversão, spin, conectores formais e figuras retóricas, e depois reescreva um trecho de forma mais honesta ou mais impactante, lendo as duas versões em voz alta.

1. What's the difference between persuasion and manipulation?
2. Which euphemism annoys you most?
3. Should contracts by law be written in plain language?
4. Which rhetorical figure do you find most powerful?
5. Can rhetoric make the world better?

## 🚀 Mini-projeto

**"Spin vs. truth":** em grupos, criem uma campanha fictícia (política ou de produto) com (1) um discurso de lançamento cheio de recursos retóricos, (2) um comunicado com spin sobre um problema, (3) a versão honesta desse comunicado e (4) um termo de uso com letras miúdas + resumo em linguagem simples. A turma avalia a ética e a eficácia de cada peça.
