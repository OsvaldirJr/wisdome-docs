# Review — Knowledge and Uncertainty
**C2-M3** — Revise graus de certeza, voz acadêmica, hipóteses complexas e comparações sofisticadas.

## O que você aprendeu neste módulo
- Graduar certeza com precisão (in all likelihood, can't possibly have, needn't necessarily)
- Construir sintagmas nominais complexos no estilo acadêmico
- Usar hipóteses complexas (would that, as though + irreal, if need be)
- Comparar com nuance (not so much X as Y, all the more, no less than)

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. ___, the results will be published in May.  
   ( ) In all likelihood · ( ) In all likelihoods · ( ) With all likely
2. Lima ___ that the sample was small. (admits)  
   ( ) acknowledges · ( ) contends · ( ) refutes
3. She spoke as though she ___ there herself.  
   ( ) had been · ( ) has been · ( ) is
4. It's not so much a problem ___ a challenge.  
   ( ) as · ( ) but · ( ) than
5. A ___ study found clear effects.  
   ( ) three-year · ( ) three-years · ( ) three year's

### Exercise 2 — Key word transformations

_Complete the second sentence using the word in CAPS (3–8 words)._

1. It's impossible that he wrote this alone. (POSSIBLY) → He ___ this alone.
2. I wish I had known earlier! (WOULD) → ___ earlier!
3. The task was much harder than we thought. (NOWHERE) → The task was ___ as we thought.

### Exercise 3 — Translate

_Translate into English._

1. Isso não precisa necessariamente ser ruim.
2. Ela agiu como se nada tivesse acontecido.
3. Quanto mais você sabe, menos certeza tem.

## 🎤 Free conversation

Faça uma apresentação de 5 minutos no estilo "academic talk": escolha uma questão ainda em aberto (científica, histórica ou social), resuma duas ou três fontes com verbos de citação, indique graus de certeza com precisão, inclua um contrafactual e conclua com uma comparação que corrija um equívoco comum ("It's not so much X as Y").

1. What is something that most people are too certain about?
2. How do you judge whether a source is reliable?
3. Which historical what-if fascinates you most?
4. Which cognitive bias affects you most?
5. Is uncertainty a weakness or a strength?

Façam revisão por pares entre os colegas usando um checklist de voz acadêmica.
