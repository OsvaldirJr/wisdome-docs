# Review — Small Talk
**B1-M1** — Revise tag questions, present perfect para experiências, etiqueta e formas de tratamento.

## O que você aprendeu neste módulo
- Puxar e manter uma conversa casual com desconhecidos
- Confirmar informações com tag questions
- Falar sobre experiências de vida com o present perfect
- Entender e explicar regras de etiqueta de diferentes culturas
- Escolher o nível de formalidade adequado (nomes, títulos, tratamento)

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. You work with Ana, ___?  
   ( ) isn't it · ( ) don't you · ( ) aren't you
2. ___ you ever been to Africa?  
   ( ) Did · ( ) Have · ( ) Were
3. I ___ Lisbon in 2022.  
   ( ) visited · ( ) have visited
4. You're ___ to bow in Japan.  
   ( ) suppose · ( ) supposed · ( ) supposing
5. Would you mind ___ the door?  
   ( ) to close · ( ) closing · ( ) close

### Exercise 2 — Mixed practice

_Complete the sentences._

1. She hasn't called yet, ___ she?
2. I've never ___ (fly) in a helicopter.
3. It's ___ to talk with your mouth full. (grosseiro)
4. Good morning, ___ Lopez. (mulher, formal)

## 🎤 Free conversation

Grave um vídeo de 2 minutos se apresentando em um evento internacional: puxe assunto com uma tag question, conte duas experiências de vida (present perfect + simple past) e explique um costume brasileiro que estrangeiros deveriam conhecer.

1. How would you start a conversation at an international event?
2. What's the most interesting thing you've ever done?
3. Have you ever been to another country? What was it like?
4. What are foreigners supposed to know about Brazil?
5. How do you like to be addressed at work?
