# Review — What If?
**B1-M6** — Revisão final do Nível B1! Faça os exercícios, a conversa final e o projeto antes de seguir para o B1+.

## O que você aprendeu neste módulo
- Falar de fatos gerais e consequências reais com zero e first conditional
- Imaginar situações hipotéticas com o second conditional
- Usar unless, as soon as, when e until para falar do futuro
- Expressar desejos com I wish
- Manter uma conversa livre de 5 minutos sobre temas variados

## ✏️ Review exercises

### Exercise 1 — Conditionals review

_Choose the correct option._

1. If you heat ice, it ___.  
   ( ) melts · ( ) will melt · ( ) would melt
2. If it ___ tomorrow, we'll stay home.  
   ( ) rains · ( ) will rain · ( ) rained
3. If I ___ you, I'd apologize.  
   ( ) am · ( ) were · ( ) would be
4. ___ you hurry, you'll be late.  
   ( ) If · ( ) Unless · ( ) As soon as
5. I wish I ___ speak Japanese.  
   ( ) can · ( ) could · ( ) would

### Exercise 2 — B1 general review

_Questions from the whole B1 level._

1. She doesn't eat meat, ___?  
   ( ) does she · ( ) doesn't she · ( ) is she
2. Have you finished ___?  
   ( ) already · ( ) yet · ( ) still
3. Would you mind ___ the window?  
   ( ) open · ( ) to open · ( ) opening
4. I had my hair ___ yesterday.  
   ( ) cut · ( ) cutting · ( ) to cut
5. It is ___ that the house is haunted.  
   ( ) say · ( ) said · ( ) saying
6. By the time we arrived, they ___.  
   ( ) left · ( ) had left · ( ) have left

## 🎤 Free conversation

Conversa final do B1: grave um vídeo de 3 a 5 minutos respondendo às perguntas abaixo sem ler, usando as estratégias de fluência. Depois, compare com seus vídeos do A1 e do A2.

1. Tell me about yourself and your English journey.
2. What's the most interesting experience you've ever had?
3. What would you change about your life if you could?
4. What are your goals for the next year? What will you do if things go wrong?
5. What advice would you give someone who is starting to learn English?

## 🚀 Mini-projeto

**Projeto final B1 — "My TED-style talk":** prepare e grave uma mini-palestra de 3 a 4 minutos sobre um tema que você domina ou ama (sua profissão, um hobby, uma experiência que mudou sua vida). Estrutura: uma história pessoal (tempos narrativos), o que você aprendeu (present perfect), uma ideia para o público (should / if) e um convite final (imagine if...). Esse é o aquecimento para o B1+, que é todo baseado em TED Talks! 🎤
