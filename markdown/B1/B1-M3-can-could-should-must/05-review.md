# Review — Can, Could, Should, Must
**B1-M3** — Revise todos os modais: habilidade, pedidos, conselhos, obrigação e possibilidade.

## O que você aprendeu neste módulo
- Falar de habilidades presentes, passadas e futuras (can, could, be able to)
- Fazer pedidos e favores com diferentes níveis de formalidade
- Dar conselhos e recomendações com should, ought to e had better
- Falar de regras, obrigações e proibições (must, have to, don't have to, mustn't)
- Expressar possibilidade e fazer deduções (might, may, could, must)

## ✏️ Review exercises

### Exercise 1 — Choose the correct modal

_Choose the correct option._

1. I ___ swim when I was six.  
   ( ) can · ( ) could · ( ) must
2. ___ you do me a favor?  
   ( ) Could · ( ) Must · ( ) Should
3. You look sick. You ___ see a doctor.  
   ( ) should · ( ) mustn't · ( ) might
4. You ___ wear a suit. It's a casual party.  
   ( ) mustn't · ( ) don't have to · ( ) can't
5. Take a jacket. It ___ get cold tonight.  
   ( ) might · ( ) must · ( ) should to

### Exercise 2 — Modals in context

_Complete with the correct modal form._

1. Next year, I'll ___ ___ to speak English fluently. (habilidade, futuro)
2. Yesterday I ___ ___ take a taxi because the subway was closed. (obrigação, passado)
3. If I ___ you, I'd accept the offer.

### Exercise 3 — Translate

_Translate into English._

1. Você se importaria de me buscar?
2. É melhor você ir agora.
3. Você não precisa pagar.
4. Ele deve estar cansado.

## 🎤 Free conversation

Sessão SAM livre: responda às perguntas por 2 a 3 minutos, desenvolvendo cada resposta com exemplos. Use o máximo de modais diferentes.

1. What can you do now that you couldn't do five years ago?
2. What's a favor you would never ask anyone?
3. What should the government do to improve education?
4. What do you have to do this week that you don't want to?
5. What might the world be like in 2050?
