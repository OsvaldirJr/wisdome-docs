# Review — Life So Far
**B1-M2** — Revise o present perfect em todas as formas e o contraste com o simple past.

## O que você aprendeu neste módulo
- Falar há quanto tempo algo acontece com for e since
- Falar de tarefas concluídas ou pendentes com already, yet e just
- Escolher entre present perfect e simple past com segurança
- Falar de atividades em andamento até agora com o present perfect continuous
- Descrever minha trajetória profissional em uma entrevista

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. I've lived here ___ 2019.  
   ( ) for · ( ) since · ( ) ago
2. Have you finished ___?  
   ( ) already · ( ) yet · ( ) just
3. I ___ him last week.  
   ( ) saw · ( ) 've seen · ( ) 've been seeing
4. How long ___ you known her?  
   ( ) do · ( ) did · ( ) have
5. I'm tired. I ___ all day.  
   ( ) 've worked · ( ) 've been working · ( ) work

### Exercise 2 — Mixed tenses

_Complete with the correct form of the verb._

1. She ___ (work) at the bank for 20 years. She retired in 2020.
2. We ___ (just / arrive). Where are you?
3. I ___ (study) Spanish since March, but I can't speak much yet.
