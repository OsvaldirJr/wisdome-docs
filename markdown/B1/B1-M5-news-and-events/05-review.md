# Review — News and Events
**B1-M5** — Revise voz passiva, past perfect, tempos narrativos e linguagem de mídia.

## O que você aprendeu neste módulo
- Entender e escrever manchetes e notícias curtas
- Usar a voz passiva no presente e no passado
- Ordenar acontecimentos com o past perfect
- Combinar os tempos narrativos para relatar eventos
- Avaliar a confiabilidade de uma notícia e expressar dúvida

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. This bridge ___ in 1974.  
   ( ) built · ( ) was built · ( ) had built
2. When I arrived, the show ___.  
   ( ) already started · ( ) had already started · ( ) has already started
3. We ___ when the earthquake happened.  
   ( ) slept · ( ) were sleeping · ( ) had slept
4. It is ___ that the castle is haunted.  
   ( ) said · ( ) saying · ( ) say
5. The news ___ surprising.  
   ( ) are · ( ) is · ( ) were

### Exercise 2 — Mixed tenses

_Complete with the correct form of the verb._

1. Portuguese ___ (speak) in nine countries.
2. She was nervous because she ___ (never / fly) before.
3. Hundreds of people ___ (rescue) after the flood.

### Exercise 3 — Translate

## 🎤 Free conversation

Apresente um "telejornal" de 2 minutos com três notícias (reais ou inventadas): uma sobre uma invenção ou monumento (passiva), uma com uma sequência de eventos (past perfect) e uma sobre clima ou desastre (tempos narrativos). Termine com um alerta sobre fake news.

1. What's the most important news story of this year, in your opinion?
2. When was your city founded? What is it known for?
3. Tell me about a time you arrived too late for something.
4. What natural disasters worry you the most?
5. How do you decide if a news source is reliable?
