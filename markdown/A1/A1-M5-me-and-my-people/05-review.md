# Review — Me and My People
**A1-M5** — Revise família, descrições, objetos e profissões.

## O que você aprendeu neste módulo
- Apresentar os membros da minha família
- Descrever pessoas com adjetivos simples
- Identificar e perguntar sobre objetos
- Dizer minha profissão e perguntar a de outra pessoa

## ✏️ Review exercises

### Exercise 1 — Escolha a correta

_Choose the correct option._

1. This is ___ car.  
   ( ) my father's · ( ) the car of my father · ( ) my father
2. ___ are my children.  
   ( ) This · ( ) These · ( ) That
3. She's ___ architect.  
   ( ) a · ( ) an · ( ) —
4. My friends are very ___.  
   ( ) funnys · ( ) funny · ( ) a funny
5. What does he ___?  
   ( ) look like · ( ) like · ( ) looks like

### Exercise 2 — Família

_Complete with the correct family word._

1. My father's sister is my ___.
2. My mother's father is my ___.
3. My brother's son is my ___.
4. My wife's mother is my ___.

## 🎤 Free conversation

Escolha 3 pessoas importantes da sua vida e fale sobre cada uma (quem é, como é, o que faz).

1. Who is this person?
2. What's he/she like?
3. What does he/she look like?
4. What does he/she do?
5. Where does he/she work?
