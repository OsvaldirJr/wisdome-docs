# Review — He, She, It
**A1-M3** — Revise a 3ª pessoa, compras e transporte.

## O que você aprendeu neste módulo
- Falar sobre a rotina e os hábitos de outras pessoas
- Fazer perguntas sobre outra pessoa com does
- Perguntar preços e quantidades em compras
- Dizer como vou para os lugares

## ✏️ Review exercises

### Exercise 1 — Escolha a correta

_Choose the correct option._

1. My brother ___ in Recife.  
   ( ) live · ( ) lives · ( ) living
2. She ___ have a car.  
   ( ) don't · ( ) doesn't · ( ) isn't
3. ___ he speak English?  
   ( ) Do · ( ) Does · ( ) Is
4. How ___ money do you need?  
   ( ) much · ( ) many
5. I go to work ___ bus.  
   ( ) by · ( ) on · ( ) in the

### Exercise 2 — 3ª pessoa

_Complete with the verb in the correct form._

1. Lia ___ (study) law.
2. He ___ (not / like) traffic.
3. Where ___ your dad ___ (work)?
4. The bus ___ (take) 30 minutes.

### Exercise 3 — Traduza

_Translate into English._

1. Ela não lava a louça.
2. Quanto custam estes tênis?
3. Ele vai a pé para o trabalho.
4. Quantas pessoas moram aqui?

## 🎤 Free conversation

Entreviste alguém (ou imagine) e depois conte para a turma sobre essa pessoa usando a 3ª pessoa.

1. Where does he/she live and work?
2. How does he/she get to work?
3. What does he/she do at home?
4. What does he/she buy online?
5. What doesn't he/she like?

## 🚀 Mini-projeto

**Meet my person:** grave um vídeo de 1 a 2 minutos apresentando uma pessoa real (familiar, amigo ou celebridade): onde mora, o que faz, rotina, como se locomove e algo que ela não faz.
