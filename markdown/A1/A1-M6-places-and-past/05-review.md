## ✏️ Review exercises

### Exercise 1 — Revisão do módulo

_Choose the correct option._

1. ___ two bathrooms in my apartment.  
   ( ) There is · ( ) There are · ( ) Have
2. The bank is ___ the pharmacy and the café.  
   ( ) between · ( ) next · ( ) across
3. She ___ speak Japanese.  
   ( ) can · ( ) cans · ( ) can to
4. We ___ at the beach last Sunday.  
   ( ) was · ( ) were · ( ) are
5. I ___ to a great restaurant yesterday.  
   ( ) go · ( ) goed · ( ) went

### Exercise 2 — Revisão geral do A1

_Questions from the whole A1 level._

1. I ___ 28 years old.  
   ( ) have · ( ) am · ( ) is
2. This is ___ car. (do meu pai)  
   ( ) my father's · ( ) my father · ( ) of my father
3. Can I ___ a latte, please?  
   ( ) want · ( ) have · ( ) take to
4. I ___ check my phone in bed.  
   ( ) always · ( ) am always · ( ) always am
5. ___ your sister work on Saturdays?  
   ( ) Do · ( ) Does · ( ) Is
6. How ___ apps do you use?  
   ( ) much · ( ) many

## 🎤 Free conversation

Apresentação final do A1: fale por 2 minutos sobre você, sem ler. Use as perguntas como roteiro.

1. Who are you? (name, age, city, job)
2. Tell me about your family and your home.
3. What's your routine like? What do you like doing?
4. What can you do well?
5. What did you do last weekend?

## 🚀 Mini-projeto

**Projeto final A1 — "This is me":** grave um vídeo de 2 a 3 minutos apresentando sua vida: quem você é, sua família, sua casa e bairro, sua rotina, o que você sabe fazer e o que fez no último fim de semana. Esse vídeo é o seu "antes" — no final do A2 você vai gravar de novo e comparar!
