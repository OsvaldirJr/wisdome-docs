## ✏️ Review exercises

### Exercise 1 — To be

_Choose the correct option._

1. My parents ___ from Bahia.  
   ( ) is · ( ) are · ( ) am
2. ___ she Canadian?  
   ( ) Are · ( ) Is · ( ) Do
3. I ___ 30 years old.  
   ( ) have · ( ) am · ( ) is
4. It ___ a big city.  
   ( ) is · ( ) are · ( ) —
5. Is Pedro your brother? Yes, he ___.  
   ( ) is · ( ) 's · ( ) are

### Exercise 2 — Possessivos

_Complete with the correct possessive adjective._

1. Lucas and ___ wife are from Recife.
2. Ana and ___ brother are students.
3. We love ___ new apartment.
4. What's ___ name? (perguntando a alguém)

### Exercise 3 — Escreva por extenso
