# Review — Out in the World
**A2-M6** — Revisão final do Nível A2! Faça os exercícios e o projeto final antes de seguir para o B1.

## O que você aprendeu neste módulo
- Fazer check-in em hotel e resolver situações no aeroporto
- Fazer pedidos formais com Could you...? e May I...?
- Explicar sintomas simples e dar conselhos com should
- Usar some, any, much, many, a lot of corretamente
- Fazer uma reclamação educada e pedir uma solução

## ✏️ Review exercises

### Exercise 1 — Module review

_Choose the correct option._

1. ___ you call a taxi for me, please?  
   ( ) Could · ( ) May · ( ) Should
2. You ___ see a doctor.  
   ( ) should · ( ) should to · ( ) shoulds
3. We don't have ___ milk.  
   ( ) some · ( ) any · ( ) many
4. How ___ eggs do you need?  
   ( ) much · ( ) many
5. I'd like to make a ___.  
   ( ) reclamation · ( ) complaint · ( ) complain

### Exercise 2 — A2 general review

_Questions from the whole A2 level._

1. I ___ afraid of heights.  
   ( ) have · ( ) am · ( ) do
2. Look! It ___.  
   ( ) snows · ( ) is snowing · ( ) snowed
3. I ___ cooking when the phone rang.  
   ( ) was · ( ) were · ( ) did
4. This is ___ city in the world!  
   ( ) the most beautiful · ( ) the beautifulest · ( ) more beautiful
5. We ___ to Peru next month. We booked the flights.  
   ( ) 're flying · ( ) fly · ( ) will to fly
6. Whose phone is this? It's ___.  
   ( ) my · ( ) mine · ( ) me

## 🎤 Free conversation

Apresentação final do A2: fale por 2 a 3 minutos, sem ler. Use as perguntas como roteiro e procure usar todos os tempos verbais do nível.

1. How are you these days, and what's different in your life right now?
2. Tell me a story about a trip or a funny moment (past simple and continuous).
3. Compare your city with another place you know.
4. What are your plans for the next year? What do you think will happen?
5. Tell me about a problem you had (hotel, restaurant, health) and how you solved it.
