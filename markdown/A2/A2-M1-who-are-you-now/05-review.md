# Review — Who Are You Now?
**A2-M1** — Revise o verbo to be em profundidade, perguntas, datas e posse.

## O que você aprendeu neste módulo
- Usar o verbo to be com segurança em todas as formas
- Falar sobre sentimentos e estados (hungry, late, nervous)
- Fazer perguntas com question words + to be
- Dizer datas, aniversários e números ordinais
- Perguntar e dizer de quem é algo (whose, mine, yours)

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. I ___ afraid of spiders.  
   ( ) have · ( ) am · ( ) do
2. This class is so ___!  
   ( ) bored · ( ) boring
3. ___ old is your car?  
   ( ) How · ( ) What · ( ) Which
4. My birthday is ___ March 8th.  
   ( ) in · ( ) on · ( ) at
5. Is this pen ___?  
   ( ) your · ( ) yours · ( ) you

## 🎤 Free conversation

Grave um áudio de 1 a 2 minutos se reapresentando: como você está, como é sua vida digital, sua data favorita do ano e um objeto importante para você.

1. How are you these days, really?
2. Are you a morning person or a night owl?
3. What's your favorite app? Why?
4. When's your birthday? How do you celebrate?
5. What object is really important to you? Whose was it before?

## 🚀 Mini-projeto

**Group calendar:** crie com a turma (ou família) um calendário compartilhado em inglês com aniversários, feriados e prazos importantes do próximo trimestre. Cada pessoa adiciona 3 datas e descreve uma delas em voz alta.
