# Review — Stories
**A2-M3** — Revise o passado completo: was/were, simple past, past continuous e narrativas.

## O que você aprendeu neste módulo
- Usar was/were em todas as formas
- Usar o simple past com verbos regulares e irregulares
- Fazer perguntas e negativas com did/didn't
- Descrever o que estava acontecendo com past continuous
- Contar uma história curta com começo, meio e fim

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. ___ you at the party last night?  
   ( ) Did · ( ) Were · ( ) Was
2. She didn't ___ the email.  
   ( ) sent · ( ) send · ( ) sends
3. I ___ when you called.  
   ( ) slept · ( ) was sleeping · ( ) sleeping
4. It was late, ___ we went home.  
   ( ) because · ( ) so · ( ) but
5. There ___ a lot of cars on the road.  
   ( ) was · ( ) were · ( ) had

## 🎤 Free conversation

Grave um áudio de 2 minutos contando uma história real da sua vida (viagem, acidente engraçado, um encontro importante). Use todos os tempos do passado deste módulo.

1. Where were you and what were you doing?
2. What happened suddenly?
3. What did you do then?
4. How did it end?
5. How did you feel?

## 🚀 Mini-projeto

**Story night:** organize uma "noite de histórias" com a turma (ou grave um mini-podcast): cada pessoa conta uma história de 1 a 2 minutos e os outros reagem e fazem perguntas. Bônus: vote na melhor história!
