# Review — Better or Worse?
**A2-M4** — Revise comparativos, superlativos, too/enough e as...as.

## O que você aprendeu neste módulo
- Comparar produtos, lugares e pessoas
- Usar comparativos de adjetivos curtos, longos e irregulares
- Dizer qual é o melhor, o pior, o mais barato
- Usar too, enough e as...as para avaliar opções
- Ler e escrever avaliações de produtos e lugares

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. The subway is ___ than the bus.  
   ( ) fast · ( ) faster · ( ) more fast
2. This is ___ restaurant in town.  
   ( ) the better · ( ) the best · ( ) best
3. Lisbon is ___ expensive than London.  
   ( ) less · ( ) least · ( ) fewer
4. The box isn't ___.  
   ( ) enough big · ( ) big enough · ( ) too big enough
5. My phone is as old ___ yours.  
   ( ) than · ( ) as · ( ) that

### Exercise 2 — Comparatives and superlatives

_Complete with the correct form._

1. Today is ___ (hot) day of the year.
2. My new apartment is ___ (comfortable) than the old one.
3. The traffic is ___ (bad) than last year.

### Exercise 3 — Translate

_Translate into English._

1. É caro demais para mim.
2. É a cidade mais bonita do Brasil.
3. Não é tão bom quanto o original.

## 🎤 Free conversation

Grave um vídeo de 1 a 2 minutos fazendo um "review" de um produto, lugar ou app que você usa: compare com outras opções, diga o que é o melhor e o pior e dê uma nota.

2. How is it better or worse than other options?

4. What's the worst thing?
5. How many stars do you give it? Why?
