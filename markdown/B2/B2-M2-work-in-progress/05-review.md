## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. By 2030, I ___ my degree.  
   ( ) will finish · ( ) will have finished · ( ) will be finishing
2. This time tomorrow, I ___ to Paris.  
   ( ) 'll fly · ( ) 'll be flying · ( ) 'll have flown
3. I knew you ___ like the gift.  
   ( ) will · ( ) would · ( ) were going
4. We'll sign, provided that you ___ the price.  
   ( ) keep · ( ) will keep · ( ) kept
5. Sorry ___, but I need to add something.  
   ( ) for interrupt · ( ) to interrupt · ( ) interrupting

### Exercise 2 — Mixed practice

_Complete with the correct form._

1. In May, I ___ (work) here for ten years.
2. I ___ (about / leave) when the client called.
3. If we ___ (pay) upfront, would you give us a discount?
4. So, to sum up, we ___ (agree) to launch in June.

## 🎤 Free conversation

Grave um vídeo de 3–4 minutos simulando parte de uma reunião que você conduz: abra, apresente a pauta, "responda" a uma interrupção, negocie um ponto com uma condição e encerre com resumo e action points. Depois, fale 1 minuto sobre onde estará na carreira daqui a cinco anos.

1. What will you have achieved professionally by 2030?
2. Tell me about a plan that fell through and what happened next.
3. What's the most important thing to remember in a negotiation?
4. How would you run a perfect meeting?
5. How has your confidence in professional English changed?
