# Review — What If...?
**B2-M4** — Revise third conditional, mixed conditionals, wish/if only e alternativas ao if.

## O que você aprendeu neste módulo
- Falar de hipóteses no passado (third conditional)
- Ligar passado e presente com mixed conditionals
- Expressar arrependimentos e desejos (wish + past perfect, if only)
- Usar alternativas ao if (supposing, provided, otherwise, but for)

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. If I ___ about the traffic, I would have left earlier.  
   ( ) knew · ( ) had known · ( ) would know
2. If I had taken the job, I ___ in London now.  
   ( ) would live · ( ) would have lived · ( ) had lived
3. I wish I ___ that comment. Now she's upset.  
   ( ) didn't make · ( ) hadn't made · ( ) wouldn't make
4. It's high time you ___ to the doctor.  
   ( ) go · ( ) went · ( ) have gone
5. Take a coat ___ it gets cold.  
   ( ) if · ( ) in case · ( ) otherwise

### Exercise 2 — Transform

_Rewrite the sentences as instructed._

1. I didn't study, so I failed. (third conditional)
2. I'm not brave, so I didn't speak up. (mixed conditional)
3. If it hadn't been for the map, we would have got lost. (BUT FOR)

## 🎤 Free conversation

Grave um vídeo de 4 minutos chamado "Crossroads": conte um momento decisivo da sua vida (third conditional), como sua vida seria hoje se você tivesse escolhido diferente (mixed), algo de que você se arrepende e algo que deseja (wish), e o que você faz hoje para se preparar para o futuro (in case / otherwise).

1. What would have happened if you hadn't made your most important decision?
2. Where would you be now if you'd chosen a different path?
3. What do you wish you had done differently?
4. What do you wish people around you would do?
5. What's your plan B in case things go wrong?

## 🚀 Mini-projeto

**"Sliding doors" short film:** em grupo, escrevam e gravem um curta (3–5 minutos) com duas versões da mesma história: uma pequena escolha muda tudo. Usem third e mixed conditionals no diálogo final, quando os personagens refletem sobre o que poderia ter sido, e wish / if only para os arrependimentos.
