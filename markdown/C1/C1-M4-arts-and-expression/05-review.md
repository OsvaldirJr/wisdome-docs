- Usar cleft sentences avançadas para focar e contrastar

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. It's a ten-___ walk to the museum.  
   ( ) minutes · ( ) minute · ( ) minute's
2. The ending was totally ___. (PREDICT)  
   ( ) unpredictable · ( ) inpredictable · ( ) unpredictible
3. It's ___ the best Brazilian film of the decade.  
   ( ) arguably · ( ) supposedly · ( ) eventually
4. ___ I want is an honest answer.  
   ( ) All what · ( ) All · ( ) What all
5. He ___ into the room, soaked and exhausted.  
   ( ) staggered · ( ) strolled · ( ) tiptoed

### Exercise 2 — Word formation

_Use the word in CAPS to form a word that fits the gap._

1. The show was a huge ___. (APPOINT)
2. Critics praised the film's ___. (ORIGINAL)
3. His comments were completely ___. (RELEVANT)

3. O que ela fez foi sair sem dizer nada.

## 🎤 Free conversation

Grave um vídeo de 5 minutos no estilo "culture vlog": conte uma história curta com linguagem descritiva, faça uma minicrítica de um filme ou série (formação de palavras), comente com atitude e humor (comment adverbs) e defenda sua opinião sobre o que é arte (cleft sentences).

1. What's the best story you've ever heard, and why?
2. Which film or series is the most overrated of all time?
3. What's something you find funny that others don't?
4. Is all art equally valuable?
5. What would you create if you were an artist?

## 🚀 Mini-projeto

**"Our cultural magazine":** em grupos, criem uma revista cultural digital com (1) um conto curto (show, don't tell), (2) duas críticas (filme/série e livro/exposição), (3) uma coluna de humor e (4) um artigo de opinião sobre arte. Cada texto deve destacar as estruturas do módulo. Publiquem para a turma e votem no melhor texto.
