- Fazer um pitch persuasivo com recursos retóricos

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. Little ___ that the company would collapse.  
   ( ) they knew · ( ) did they know · ( ) knew they
2. There has been a ___ increase in remote work.  
   ( ) significantly · ( ) significant · ( ) signify
3. With so many applicants, there's ___ to be a delay.  
   ( ) bound · ( ) well · ( ) hardly
4. The bus has gone. We ___ as well walk.  
   ( ) may · ( ) should · ( ) bound
5. What we need ___ more time.  
   ( ) it is · ( ) is · ( ) are

### Exercise 2 — Transform

_Rewrite the sentences as instructed._

1. We realized the problem only when customers complained. (Only when...)
2. Prices rose sharply, so demand fell. (nominalise: The sharp rise...)
3. Our users gave us the idea. (It was...)

## 🎤 Free conversation

Apresente em 5 minutos uma análise da "next big disruption" no seu setor: conte uma história de disrupção (com inversões), descreva o impacto em linguagem formal (nominalização), faça previsões com modais avançados e termine com um mini-pitch de uma solução (com recursos retóricos).

1. Which industry in Brazil is most likely to be disrupted next?
2. What makes a great leader in times of change?
3. Is the gig economy good or bad for workers?
4. What's the most important skill for the future of work?
5. If you had to pitch yourself to an employer in one minute, what would you say?

## 🚀 Mini-projeto
