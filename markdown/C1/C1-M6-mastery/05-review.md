## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. It might be worth ___ the figures again.  
   ( ) to check · ( ) checking · ( ) check
2. ___ you require assistance, please contact reception.  
   ( ) Should · ( ) Would · ( ) Had
3. ___ the company to close, many jobs would be lost.  
   ( ) Were · ( ) Should · ( ) Had
4. Formal equivalent of "put off":  
   ( ) postpone · ( ) tolerate · ( ) discover
5. Formal closing for "Dear Sir or Madam" (British):  
   ( ) Yours faithfully · ( ) Cheers · ( ) Love

### Exercise 2 — Transform

## 🎤 Free conversation

**Simulado de prova oral C1 (15 minutos, em dupla):** Parte 1 — perguntas pessoais com respostas desenvolvidas. Parte 2 — compare duas fotos por 1 minuto ("working from home vs. in an office") e especule. Parte 3 — tarefa colaborativa de 3 minutos ("What makes a city a good place to live?") e decisão final. Parte 4 — discussão abstrata (perguntas abaixo). Grave e avalie: variedade, precisão, fluência, interação e pronúncia.

1. How has the way people communicate changed in the last twenty years?
2. Is it possible to be completely objective when giving feedback?
3. Should everyone be required to study a foreign language?
4. What does success mean to you?
5. What will you do with your English from now on?
