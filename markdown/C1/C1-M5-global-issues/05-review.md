## O que você aprendeu neste módulo
- Falar do futuro com formas formais (be set to, be on the verge of, be due to)
- Usar multi-word verbs com sentido abstrato
- Relatar informações com distanciamento
- Escrever um ensaio discursivo C1 coeso

## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. Food prices are set ___ rise again.  
   ( ) to · ( ) for · ( ) on
2. The species is on the brink ___ extinction.  
   ( ) to · ( ) of · ( ) for
3. The problem stems ___ a lack of investment.  
   ( ) from · ( ) in · ( ) of
4. The suspect is believed ___ the country.  
   ( ) to leave · ( ) to have left · ( ) leaving
5. ___ measures have been introduced in other countries.  
   ( ) Such · ( ) Such a · ( ) So

### Exercise 2 — Transform

_Rewrite the sentences as instructed._

1. If we want to succeed, we must cooperate. (If we are to...)
2. Migrants represent 10% of the workforce. (account)
3. It is alleged that the mayor accepted bribes. (The mayor...)

## 🎤 Free conversation

Faça uma apresentação de 5 minutos no formato "policy briefing" sobre uma questão global (clima, migração ou desinformação): apresente previsões (futuro formal), explique causas e consequências (multi-word verbs), relate informações com distanciamento e termine com uma recomendação bem argumentada (coesão).

1. Which global issue will define the next decade?
2. Can individuals make a real difference to global problems?
3. How should Brazil respond to climate migration?
4. Who is responsible for stopping misinformation?
5. If you could change one global policy, what would it be?

## 🚀 Mini-projeto

**"Model UN":** a turma simula uma sessão da ONU sobre uma questão global. Cada grupo representa um país, prepara um discurso de 2 minutos (com futuro formal e distanciamento), negocia com os outros e, no final, todos redigem juntos uma resolução de 300 palavras, coesa e formal.
