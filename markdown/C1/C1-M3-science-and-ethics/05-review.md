## ✏️ Review exercises

### Exercise 1 — Choose the correct option

_Choose the correct option._

1. The error must ___ by the software.  
   ( ) have caused · ( ) have been caused · ( ) be causing
2. I'm having my car ___ tomorrow.  
   ( ) repair · ( ) repaired · ( ) repairing
3. The board insisted that she ___ the report.  
   ( ) rewrites · ( ) rewrite · ( ) rewrote
4. There was a sharp rise ___ inflation.  
   ( ) of · ( ) in · ( ) on
5. ___ hard he tried, he failed.  
   ( ) However · ( ) Whatever · ( ) No matter

### Exercise 2 — Transform

_Rewrite the sentences as instructed._

1. If you need help, call us. (Should...)
2. Sales fell dramatically. (There was...)
3. Although it sounds strange, it's true. (Strange though...)

### Exercise 3 — Translate

_Translate into English._

1. Roubaram o celular dele no metrô. (have something done)
2. É essencial que todos sejam informados.
3. Correlação não implica causalidade.

## 🎤 Free conversation

Faça uma apresentação de 5 minutos sobre uma questão de ciência e ética (edição genética, IA na medicina, testes em animais, vacinação obrigatória): explique o contexto científico (passivas), apresente dados com hedging, faça recomendações formais (subjuntivo) e argumente reconhecendo o lado oposto (concessão).

1. Which scientific advance excites you most? Which worries you most?
2. Should scientists be free to research anything they want?
3. How can ordinary people judge scientific claims?
4. Is it ever right to break the rules for a good cause?
5. Who should decide the ethical limits of technology?
